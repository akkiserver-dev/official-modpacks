# あっきーサーバー Official Modpacks

あっきーサーバーで使用されるMinecraft Modpackを管理・公開する公式リポジトリです。

## ルール

本リポジトリでは、Modpackの管理・保守および過去の企画の再現性を確保するため、以下のディレクトリ構成および運用ルールを定めます。

### 1. ディレクトリ命名規則

各企画は、原則として独立したディレクトリで管理し、以下のいずれかの命名形式を使用してください。企画名の部分は日本語も使用可。

- `企画名-年-月`
- `企画名-年`
- `年-月`

例：

```text
create-2026-03/
technology-2026/
2025-12/
```

企画に関するファイルの追加・変更・削除は、原則として該当する企画ディレクトリ内で行ってください。

### 2. 必須ファイル

各企画ディレクトリには、最低限以下のファイルを配置してください。

| ファイル | 内容 |
|---|---|
| `modpack.md` | 企画のコンセプト、概要、目的などを記載 |
| `modpack_yy-mm_hh-mm.zip` (または`企画名_yy-mm_hh-mm.zip`) | CurseForge Modpack形式でエクスポートされたzipファイル |

`modpack_11-07_19-43.zip`のように、11月7日の19時43分にエクスポートされたものとしてバージョン管理が行えるよう**必ず**その時の日付・時刻を記録すること。

### 3. ファイル・ディレクトリ構成

KubeJSスクリプト、設定ファイル、リソースなどは、**Minecraftインスタンスのルートディレクトリを基準とした構成**で配置してください。

特にKubeJSについては、`server_scripts`、`client_scripts`、`startup_scripts`などの内部ディレクトリを企画ディレクトリ直下に分離せず、**必ず**`kubejs/`を起点として配置してください。

例：

```text
create-2026-03/
├── modpack.md
├── create-2026-03.zip
├── kubejs/
│   ├── server_scripts/
│   │   └── recipes.js
│   ├── client_scripts/
│   ├── startup_scripts/
│   └── assets/
└── config/
    └── example.toml
```

Modpack内で使用するファイルは、できる限り実際のMinecraft環境へそのまま配置できるディレクトリ構成を維持してください。

### 4. 変更・追加時の注意事項

- 異なる企画のファイルを同一ディレクトリに混在させないでください。
- 既存企画のファイルを変更する場合は、該当企画への影響を確認してください。
- 第三者のModやアセットを追加する場合は、そのライセンスおよび再配布条件を遵守してください。
- 企画の再現に必要な設定やスクリプトは、可能な限り該当企画ディレクトリ内で管理してください。

### 5. 機密情報の取り扱い

パスワード、APIキー、アクセストークン、その他の
認証情報を本リポジトリにコミットしないでください。

認証情報が必要な場合は、環境変数やGit管理対象外の
設定ファイルなどを使用してください。
